
# GitHub Implementations

These repositories were selected because they provide substantial documentation, accessible source code, examples, recognized projects or research connections, and a clear relationship to autonomous agents or autonomous scientific workflows.

## 1. The AI Scientist

**Repository:** https://github.com/SakanaAI/AI-Scientist

**What it implements:** An end-to-end automated scientific research system that can generate research ideas, write and execute code, analyze results, create visualizations, and draft scientific papers.

**Why relevant:** It is directly connected to autonomous research and provides a concrete implementation for studying where human oversight and trust calibration may be needed.

**Selection notes:** Strong research connection, substantial documentation, examples, and an explicit source-code license. Check the current license before reuse.

## 2. The AI Scientist-v2

**Repository:** https://github.com/sakanaai/ai-scientist-v2

**What it implements:** An agentic tree-search approach to automated scientific discovery, including hypothesis generation, experimentation, analysis, and manuscript generation.

**Why relevant:** Demonstrates a more agentic autonomous-science architecture and is directly relevant to long-horizon research workflows.

**Selection notes:** Includes a linked paper and workshop experiment description. Review the project's responsible-use and disclosure requirements before reuse.

## 3. Microsoft Agent Framework

**Repository:** https://github.com/microsoft/agent-framework

**What it implements:** Production-oriented single-agent and multi-agent workflows, including orchestration, human-in-the-loop patterns, observability, and stateful workflows.

**Why relevant:** Provides implementation patterns for controlled delegation and human supervision of autonomous agents.

**Selection notes:** Active project with documentation, examples, and MIT licensing. It is the successor to Microsoft's AutoGen/Semantic Kernel direction.

## 4. LangGraph

**Repository:** https://github.com/langchain-ai/langgraph

**What it implements:** Stateful agent orchestration for long-running workflows, including graph-based control, persistence, and human-in-the-loop patterns.

**Why relevant:** Research agents need explicit control over multi-step workflows, escalation, checkpoints, and human intervention.

**Selection notes:** Strong documentation, active development, examples, and a large open-source community.

## 5. LlamaIndex

**Repository:** https://github.com/run-llama/llama_index

**What it implements:** Document ingestion, indexing, retrieval, RAG, and agentic application components.

**Why relevant:** Autonomous research agents depend heavily on evidence retrieval and document-grounded reasoning. LlamaIndex provides infrastructure for connecting agents to scholarly documents and data.

**Selection notes:** Extensive documentation, examples, integrations, active maintenance, and MIT licensing.

## Implementation Selection Checklist

Before recommending an existing repository, check:

- Documentation quality
- Source-code availability
- Recent activity
- Examples/tutorials
- Reproducibility
- License
- Connection to a paper or recognized project
- Relevance to autonomous research or human-agent collaboration

Star count alone was not used as the selection criterion.
